# 工程启动、构建、部署与接手说明

## 实际技术栈

1.8.0源文件来自不可变封版，全量HTML/CSS/原生JavaScript ES Modules（.mjs）、Babylon.js9.30.0、本地图片/字体/音频/许可证均在game。没有React/Vue/Vite、TypeScript、Babel、webpack、npm run build，也不依赖网站抓取或云端生成服务。

Node.js22以上用于本地HTTP服务、测试与工具；浏览器直接执行ES Modules。Node不需要随Android APK运行。Prettier3.6.2和playwright-core1.62.1只为开发依赖，package.json、package-lock.json、.prettierrc.json都保留。node_modules未打包，可npm ci恢复；机器上的全局路径不是项目依赖。

## 从零启动

在本文件上两层，即“02-工程文件及说明”目录解压后：

```
cd game
node tools/server.mjs
```

打开http://127.0.0.1:4210/，不要求先npm install。Windows也可在工程根目录双击“启动游戏.cmd”，已安装Node时自动启动。macOS/Linux直接用node命令，勿依赖Windows脚本。不要双击index.html以file://运行：模块、字体和fetch需要HTTP/虚拟HTTPS来源。

游戏竖屏900×1600设计，页面自适应。C投币、左右或A/D瞄准、Shift细调、空格发射、P暂停、F全屏。当前投币/出票为模拟。public-IP试玩地址http://8.134.94.47/?v=1.8.0，仅供效果对照；APK应该离线带资源，不把该IP当正式运行依赖。

## 检查与测试

```
npm ci
npm run check
npm test
npm run test:baseline
npm run test:slots
npm run audit
node tools/check-release.mjs 1.8.0
```

基础核心/反馈测试不需要浏览器。浏览器测试需要Chrome/Edge，非默认位置用BROWSER_PATH指向可执行文件；Linux/macOS同样显式设置。playwright-core不会自动下载浏览器。端口冲突时先检查已有服务，不直接结束无关进程。

本包保留output/refactor-baseline/v1.7.3/game及output/releases/v1.8.0的原始清单/源码/ZIP，因此默认对照和封版检查路径可用。它们是只读参照，不是当前修改入口。唯一开发入口game/。docs是工程工具所需文档副本；主产品资料在第一部分。

已有证据：130项核心/反馈测试；480发、11,662组状态/事件对照；6奖项618组专项；5组同帧截图差0；公网投币、声音、存档、并行摇奖通过。存放output/verification。原结果证明1.8封版，不等于Android已经测试通过。

运行代码格式检查：node node_modules/prettier/bin/prettier.cjs --check src。format:check覆盖更多历史测试和工具，不要为全量格式清理混入玩法改动。

## 结构与可改范围

- src/client/app.mjs：唯一核心实例、设备、输入、帧循环与编排；接真实硬件主要从这里替换模拟器和输入来源。
- src/core：纯业务、事务、碰撞、自然补球、奖账及恢复。pet-slots子目录分开计划、实时目标、结算和校验。
- src/presentation：Babylon场景、图集、器具和珍珠引导线。
- src/feedback：已提交事件驱动的特效、音频、宠物、UI、环境；不能从动画回调重复发奖。
- assets、vendor：真实运行离线素材及许可；无外部CDN运行依赖。
- dev：明确的模拟美术预览，不是正式入口；正式包不对外开放。
- tools/tests：真实源工程的一部分；不可当作生产公开文件挂上网站。

具体职责、事件协议和修改检查清单见docs/38及第一部分完整产品规格。保持唯一球ID、发射ID、奖励ID、设备批次ID；修改原型参数需分析存档配置匹配，不是只改默认常量。

## Web发布流程

原项目无“编译dist”；部署产物就是白名单静态文件。修改后请升新版本，不能覆盖1.8.0：

1. 同步game/package.json、package-lock.json、页面版本及变更文档，完成测试。
2. Windows用game/tools/package-release.ps1 -Version 新版本 -BaselineVersion 1.8.0创建不可变发布；其他平台可按同等目录/manifest规则制作。
3. node game/tools/prepare-deployment.mjs 新版本，从冻结源提取index/style/src/assets/vendor，添加deployment.json、SHA清单及公网HTTP UUID兼容。
4. 新site上传到服务器独立release，先sha256sum校验，再切换current；旧目录保留回退。Node服务仅本地开发，现服务器由Nginx80静态托管。

现网current曾指向/var/www/bubble-arcade/releases/1.8.0-http/site。此次交付不包含SSH密钥、服务器授权或真实设备凭据。接手人若需发布权限由公司另行授予，不应把凭据打进APK。

## 存档与资源

机器键bubble-integrated-v15-machine，设备键bubble-integrated-v15-device，配音偏好bubble-arcade-announcer-choice。更换域名/端口或从浏览器移到APK是换origin，不会自动读取旧浏览器进度。正式移交有余额的机器必须显式导出/校验/导入；不能用清存储作为升级步骤。

Babylon、字体和第三方短声按assets/licenses及vendor许可保留署名。没有.blend/PSD等可编辑母文件时不可声称提供了它们；本项目实际宠物/多种图标是Canvas代码绘制，图片是现有PNG素材。生成图与历史素材的生产授权仍需公司按最终商用范围复核，文件中已有的许可记录均保留。
