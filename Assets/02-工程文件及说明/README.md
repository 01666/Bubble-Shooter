# 泡泡龙彩票街机 · 1.8.0

当前认可版本已整理为1.8.0；与1.7.3玩法和画面一致。唯一维护目录为game/，冻结产物在output/releases/v1.8.0/，旧1.6.0及历史版本保留。

本地运行直接双击“启动游戏.cmd”。Windows 10/11 无需安装 Node.js、无需联网；启动器在找不到 Node.js 时会自动使用系统 PowerShell 离线服务器。开发人员也可在game目录运行node tools/server.mjs。访问http://127.0.0.1:4210/?v=1.8.0。公网部署目标：http://8.134.94.47/?v=1.8.0，IP HTTP，不使用HTTPS。

## 当前体验

无尽公共盘面、一币10球、免费试射挑颜色、边玩边模拟出票；八排初盤、色团控制、自然顶部波次及特殊球分散；三星公开奖宝箱、爆炸/导电、低余球2–5特殊球、大消除赠球。六秒连续成功三次触发萌宠幸运机，每摇必奖，摇奖时可继续发射；常驻宠物抓杆装置、街机爆发奖字、两套女声选择和短得分声。刷新保留盘面、余球、奖励与待出票。
