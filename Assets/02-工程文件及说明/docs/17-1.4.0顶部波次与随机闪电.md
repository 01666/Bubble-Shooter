# 1.4.0 顶部波次与随机闪电

本页记录1.4.0。当前节奏和演出已更新至[1.4.1](18-1.4.1盘面节奏与演出升级.md)，覆盖本页“仅未消除时恢复”、两发缓冲及物理前沿上限的旧规则。

本轮直接重写了默认盘面策略，删除逐发按数量填洞和每24发固定十二排球潮。沿用当前美术、投币、公共接盘、双彩、星星宝箱、最后两球目标和出票账务。

参考 [Puzzle Bobble Everybubble 官方发行商关于下降天花板的说明](https://iningames.com/blogs/news/puzzle-bubble-everybubble-patch-1-01) 和 [Frozen Bubble 原项目的推进、补顶行源码](https://github.com/kthakore/frozen-bubble/blob/master/bin/frozen-bubble)。借鉴的是六角格连接、顶部推进和失去支撑后的掉落；下面的压力阈值与恢复节奏是本机无尽模式的原型设计，不宣称复制上述商业游戏的数值。

## 盘面算法

- 初始八排、72颗系统球。颜色通过持久随机流生成：有一定概率沿用左邻或上邻颜色，形成不规则色团；不再重复铺两行两列的固定花纹。
- 清除、爆破、电击、掉落产生的洞保留。不存在按本发消除数逐球填回的逻辑。
- 未消除的有效付费射击增加1点压力；成功消除减少1点。达到阈值后，下一次符合条件的无消除结算推进一整排。每次推进后重新抽3–5的阈值，初次为4。
- 顶部加入9颗；原有球整体下移一行，六角格奇偶位同步翻转，水平位置、颜色、ID与相对连接不变。
- 单发消除和掉落合计达到12颗，获得两发缓冲。缓冲期间不推进顶部；这不是强行制造失败或改色。
- 最深球不足七排、距上次波次至少两发、且缓冲结束后，遇到无消除结算可进入恢复波次。低于四排时一次恢复两排，仍从顶部进入，不填原洞。
- 彻底清空时开启新一波：逐行建立最多七排随机布局，受已有库存额度限制，显示“清空成功，新一波登场”。
- 高盘面暂停顶部推进。触及器具安全线或无合法落点时仍使用单独的无尽安全维护；移走的真实球暂存，不产生彩票、收星或免费奖。暂存原球优先在后续顶部波次归场，不立刻填洞。

八排是初盘密度，不是每发强制回填目标。高手消除后允许明显变空，也允许因铺球和推进自然增高。盘面占比不再由发射次数硬切换。

核心文件：`game/src/core/endless-flow.mjs` 负责颜色与波次，`board-policy.mjs` 保留建盘、额度和安全维护，`core.mjs` 传入真实结算结果。历史 `densityTarget/densityPeakRows` 字段仍兼容旧存档，分别参与初盘下限与库存预算，不再控制固定球潮。`densityEnabled=false` 保留旧策略供回归对照。

持久状态：`content.flow={version:1,pressure,threshold,grace,sinceWave,waves}`。加载仅补此状态，不重抽盘、不填洞、不改变余球和彩票义务。免费试射、投币本身、出票回执、暂停和刷新不推进压力。

## 导电球规则

导电球被同色三消、双彩匹配或炸弹引爆实际消除时激活；仅被碰到但未消除、或仅失去支撑而掉落，不激活。

每发首次激活抽取3–6个额外电击名额。同发全部导电节点共享名额，避免三个节点各自倍增。电流从导电球沿真实六邻泡泡图选路，不限颜色；遇到边缘可沿已经经过的分支回溯，不能跨越空格。原本已匹配的球可作路径桥梁，但不消耗额外名额，不重复计奖。有限盘面、断路或12段路径上限可能使实际电击少于名额。

沿线电击炸弹可触发原有爆炸闭包，电击另一导电球可继续激活。爆炸与电击共享去重集合，再统一计算脱顶掉落、收星和彩票。没有虚构额外导电彩票：直接电掉的球仍每颗1张，随之脱顶掉落每颗2张，宝箱规则沿用。

随机路线用原盘面系统球身份与节点进行确定性散列，不消耗预览采样的随机流。相同已保存局面可重放；不同局面的名额与路径不同。真实结算和弹道预测共用 `expandMechanisms`。该方法是可重放原型随机，不是安全服务端开奖。

`networkPropagated` 延续接口版本1，增加 `struckBalls`（包括沿途普通球）、沿真实中心坐标的 `steps`，保留 `activatedNodes/seeds/bombContacts`。`paidShotResolved.electricIds/electricCount` 现在包含实际被电击的普通球与节点，可能与匹配或炸弹集合交叉，不能相加当作总消除数。

表现层不再只接收三个节点。沿途普通球也进入动画：中心到中心的白芯蓝光锯齿电弧、逐段到达、球体电击缩散和蓝白碎粒。活动电弧不使用静态连线的两端30px缩进。顶部整体推进不再给每颗旧球叠金环，避免与消除抢画面。

## 验证

- 核心与反馈自动测试73项：两种策略各150发、1000发混合历史、库存与账务守恒、保存恢复、顶行几何、消除留空、压力缓冲、随机路径、真实邻接与跨色电击。
- 六组原浏览器回归：投币/出票、装填、星星宝箱、移盘、整合演出与26发逐帧检查。未发现隐藏球、异常缩放、着色器或浏览器错误。
- 新增纯导电实机测试：真实键盘射击，无炸弹干扰，5颗电击球、4段路径进入表现层，保存截图，效果到期回收。证据：`output/verification/v1.4.0-lightning/`。

上述用于原型质量检查。顶部压力、色团比例与闪电强度仍需真实试玩调节；本轮不提供生产彩票回报承诺。
