# 1.5.3 低余球特殊球数量分布

日期：2026-10-12。继承1.5.2的中上层加权位置和余1/2球变化节奏，本轮只调整每次机会的计划数量。

| 数量 | 概率 |
| --- | --- |
| 5颗 | 20% |
| 4颗 | 20% |
| 3颗 | 30% |
| 2颗 | 30% |

计划数量的期望为3.3颗。资格成立时，以机器节奏种子、机会序号和独立count标签做无状态散列，得到[0,1)均匀抽样值：小于0.2选5，小于0.4选4，小于0.7选3，其余2。数量和时机分别选定，保存在同一个机会记录中，等待余1球、无候选延后或刷新都不重抽，也不消耗出球、宝箱或双彩随机流。

同次申请允许最多5颗有相同机会ID的系统球标为炸弹。已标球的身份、位置、颜色不变；计划值requestedCount和实际登场值burstCount分别记录。当前盘面/暂存炸弹总上限仍为12，候选不足或剩余预算不足时按可用数量登场；已达到上限仍沿用延后/跳过规则，不能覆盖其他特殊属性。旧申请缺少计划数量字段时继续原来的2颗，已出现目标不追加；新申请才使用本轮分布。

登场光环显示缓存从3个扩到5个，避免第4、5颗有业务属性却缺失对应登场强调。普通奖励、炸弹爆炸范围、公共资格、购买与消耗间隔、中上层权重、登场时机、免费球与退款规则不变。

测试包括1000个等距抽样值精确验证20/20/30/30分桶及边界；2/3/4/5四种请求分别保存恢复、只出现一次、球库存/票账不增加；既有配色、波次、特殊机制和音画反馈回归。当前商业每币票量需重新统计，数量增多不代表返奖分布完全不变。
