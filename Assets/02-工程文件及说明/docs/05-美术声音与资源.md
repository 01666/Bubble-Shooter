# 美术、声音与资源

## 实现方式

当前为2.5D实现：Babylon正交场景承载图集球体、器具、宠物图层及局部3D炮口；Canvas覆盖层负责大多数爆炸、闪电、掉落与UI。3D空间感来自球体材质图、高光流动、飞行、缩放、回弹、抖动与层次，不是全场景真实3D模型。

画面设计坐标900×1600。逻辑盘面转屏幕常用x=450+逻辑x×900/9.9、y=160+(7-逻辑y)×900/9.9。Region内仍保留旧局部坐标函数，当前FullScene覆盖盘面映射；修改尺寸时应统一查验所有映射而非只改canvas。

## 主要图层

背景在Babylon场景后层；盘面、炮台、球托和收集台在场景对象层；实际弹丸及装填球前置。顶栏使用DynamicTexture HUD，宠物使用动态纹理，消除/飞票/星星/底部说明由feedback Canvas绘制，免费和故障提示是DOM。

新增提示应进入现有优先级：故障、暂停、星星庆祝、免费提示、普通通知、奖励反馈。不要让多个同级大字同时占用发射区。

## 动效关键点

- 消除：从刚被核心移除的真实球快照制作短暂缩小淡出，不恢复已删除核心球。
- 掉落：球飞下、逐渐淡出，再交接给飞票，动画不是重复奖励。
- 新球：spawnUntil驱动入场缩放，提示与光环来自boardRefilled。
- 整理：boardMaintained与boardRepositioned代表既有球退役/归位，不能被画成获得奖励。
- 装填：shotAccepted的loadedAfter确定颜色，预览球沿曲线进炮台，到位轻微回弹，转移时隐藏源位和目标位副本。
- 引导线：由核心预测轨迹采样成珍珠，渐淡渐小并隐藏最终落点；显示变化不影响真实碰撞。
- 飞票终点和出票纸条：与右下收集台坐标对齐；只有dispenseConfirmed驱动确认吐纸。
- 连锁：每次效果以shotId归组，旧清除区域遇到新补球时做遮挡，避免旧球残影和新球互相闪烁。

## 宠物和音频

现行宠物由pet/controller分配动作、优先级与冷却，dragon绘制整体连贯身体；babylon-adapter负责把动态纹理放入当前场景。旧贴图宠物隐藏，不应重新启用双宠物。

ArcadeAudio只创建一个AudioContext，包含136 BPM基础音乐和两个同步强度层。master/bgm/sfx/voice分开混音；音效有优先级、限并发及冷却。普通反应用短角色音；阶段和故障语音有较长间隔，避免机器人连续播报。音效由已提交事件或画面语义cue发出，不能由未确认碰撞提前结算。

资源目录共32个实际运行WAV。历史demo-\*.wav是演示合辑，此次未放进活跃资源目录。改文件名时需要同步audio/cues和加载逻辑，否则浏览器测试会检测资源错误。

## 美术修改检查

同时观察免费、付费、补球、连锁、大掉落、集星领奖、卡票与暂停。检查文本和边框、炮台/下一球/收集台、补球与旧特效遮挡。按普通与减少动态两种设置检查，并在360px窄窗口与完整竖屏检查。
