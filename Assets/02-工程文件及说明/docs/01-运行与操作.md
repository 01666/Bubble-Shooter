# 运行与操作

## 普通使用

1. 在项目根目录双击“启动游戏.cmd”。脚本会在后台开启本地服务并打开浏览器；Windows 10/11 没有 Node.js 时自动使用系统 PowerShell，无需联网安装软件。
2. 默认地址固定为 http://127.0.0.1:4210/。保持原地址有助于保留同一浏览器的 V15 数据。
3. 先按一次键或点击“开启音乐”，浏览器允许声音后开始播放。刷新后可能需要再次交互解锁声音。
4. 按 C 模拟投1币，增加10个可发射泡泡；空格发射。
5. 按 F 切换全屏；侧边栏属于开发演示控制台，不是最终机台管理后台。

脚本优先使用 PATH 中的 Node.js，也支持这台电脑已有的 Codex 捆绑运行时；两者都没有时使用包内的 PowerShell 离线服务器。双击 HTML 文件不能替代本地服务器，ES 模块与资源路径需要 HTTP 环境。

## 按键和手柄

| 输入              | 功能                                         |
| ----------------- | -------------------------------------------- |
| 左右方向键 / A、D | 瞄准，短按细调、长按加速                     |
| Shift + 方向键    | 更精细的瞄准                                 |
| 空格              | 发射；没有付费球时进行免费试射并轮换当前颜色 |
| C                 | 模拟投1币，增加10球                          |
| P                 | 暂停/继续                                    |
| M                 | 静音/恢复                                    |
| F                 | 全屏/退出全屏                                |
| 手柄横轴/方向键   | 瞄准，横轴有死区与非线性响应                 |
| 手柄按钮0/8/9     | 发射/模拟投币/暂停；实际设备映射需要联调     |

失去窗口焦点或隐藏页面时，玩法暂停。当前模拟出票仍由页面循环驱动，浏览器节流会降低处理速度；它不是独立于页面的硬件进程。手柄断开会暂停。

## 界面含义

- 可发射泡泡数：付费余额，不代表盘面球数。
- 待出彩票：已经赢得、还没有收到出票成功回执的彩票数。
- 底部三颗星：消除或击落星星球即可收集，集齐3颗得到本轮固定的额外奖励。
- 累计赢票：当前页面运行期间新增的赢票量，刷新后重新计数；机器总账不会随之清零。
- 免费提示：免费试射可以挑选当前颜色，但不消除盘面、不收星星、不赢票。
- 右下彩票收集台：飞票和出票反馈的视觉终点；金额/数量以顶栏及核心账务为准。

## 刷新、投币与公共盘面

这不是每次投币重新开始的一局。第一次创建机器状态时随机建盘；之后玩家连续投币、余额耗尽、换玩家、刷新页面，都会继续同一公共布局和星星进度。免费試射也不会重新洗牌。

同地址、同浏览器配置文件的 localStorage 中保存机器和模拟出票器。换端口、换浏览器、隐私模式或清理站点数据，相当于另一个本地机器实例。不要通过清理存储来解决卡票问题，因为这会同时删除待出票义务。

## 开发启动与故障处理

```powershell
cd game
node tools/server.mjs
# 临时独立实例（数据与默认4210隔离）
$env:GAME_PORT='4220'
node tools/server.mjs
```

启动脚本会检查 /health。端口被其他程序占用时不会主动结束该程序。日志位于 output/logs/。

“模拟卡票”只用于演示故障；解除后继续模拟出票。“核对模拟出票”用于有持久回执证据的 uncertain 批次。存储或配置不匹配时报错应保留原始状态，先备份和诊断，不应自动重置。

未提供正式的机器重置、账务导入导出或断电恢复管理界面，这些属于后续运营工具。
