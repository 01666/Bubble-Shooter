# 玩法、出球、难度与奖励现状

基础循环沿用1.0，当前盘面与导电规则已更新至1.4.2；准确波次、压力、缓冲和随机闪电规则见文档19、18和17。文档12、15、16中的旧盘面和导电限制已被覆盖。早期文档中的60秒、复活、Fever、小时榜、幸运值与三连倍率不代表已实现功能。

## 游戏循环

投币增加付费球→瞄准发射→吸附到六角格→同色连通达到3球消除→触发可能的连锁爆炸→无顶部支撑的球掉落→奖励入账→维护或补充公共盘面→更新下一球。没有60秒结束、通关黑屏或Game Over。余额为0时进入免费试射；公共盘面继续留给后续玩家。

## 出球与随机性

首次创建状态使用浏览器 crypto 随机种子。核心用可重放的32位线性同余流推进盘面相关随机数；星星奖励使用独立的持久随机流。它们服务于可重放原型，不是生产级安全随机或服务器开奖。

当前默认初盘72个系统球、八排，随机生成不规则色团，按真实六邻连通关系抑制超过六球的大团和长横向色条，保留两三球组合。仅影响新生成球，不事后修改既有盘面。消除留空，仅从顶部按压力和低盘面恢复波次整排推进。大消除有一发缓冲及延后入场窗口，清空开启新一波；不再逐发填洞或按固定发数切换球潮。刷新保留原布局。densityEnabled=false保留原策略供对照。

付费射击发出当前球后，当前装填色立即换成发射前的下一球颜色。结算后，从当时盘面出现的不同颜色中等概率选择新的下一球；不是按每种颜色的球数加权。在弹丸飞行中不重新抽预览。

免费发射会让球碰盘反弹并退出，同时当前装填色按五色顺序轮换。下一球、盘面、目标、随机奖励进度与账务保持不变。投币保留免费试射挑好的当前颜色。这份可选择的优势是有意产品设定，后续数值模拟必须纳入。

刷新从存档恢复盘面、随机流、阶段固定奖、余球和义务，不重新抽种子。再次投币也不重新建盘。

## 消除、爆炸、闪电和星星

导电球实际被消除时，从真实相邻泡泡图随机选择3–6个额外电击目标，不限颜色；已匹配球可作桥梁，断路时不跨空格。闪电和爆炸使用同一去重集合，然后计算掉落。仅碰撞或仅掉落不通电，导电不另加虚构彩票。

普通同色消除集合含本次发射后吸附的球，基础奖励也按实际消除集合计数。集合触及炸弹时，会引爆它的一圈邻格，可跨颜色、继续引爆其他炸弹；每个炸弹在同一发中只触发一次，每个消除球只计一次。

炸弹仅因掉落离开盘面时不会引爆邻居。掉落是在直接消除和爆炸结束后，检查与顶部连通性得到的集合，不会与直接集合重复计奖。

星星绑定本轮的系统球身份。直接消除或掉落收集；暂存、整理、归位不收集。集齐3颗时，使用本轮开始时已经抽好并保存的奖励：刷新不会重抽。奖励ID为stage-N，入账去重后才开始下一轮。

基础彩票 = 直接消除数量×1 + 掉落数量×2。完成星星轮次时，再加本轮额外奖。额外奖单次期望是6.4张，这不等于每币期望，因为完成率、技巧、选色和公共盘面都会影响实际结果。

## 无尽盘面如何持续

系统球被实际消除或掉落后，其数量计入生成额度content.credit。补充新系统球必须消耗额度；维护只是把仍存在的球移到reserve，不能当成新奖励或免费新增奖池。

守恒约束为：盘面与reserve中的系统球数量 + content.credit = 初始系统球总数。玩家发射出的球另算，系统球数不等于所有球的总数。

拥堵时进行安全维护，原球等待后续顶行波次复用；最近铺出的球和支撑路径在安全区域内优先保护。器具安全线覆盖保护：任何球底进入dangerY以下都应暂存，避免堵住炮口。没有合法落格的发射退还1个付费球；整理、归位和旧球退役不奖励彩票。

## 难度现状

没有自适应赔率、玩家画像或强制“差一点”的暗线。难度主要来自球团形状、颜色分布、射击精度、遮挡、炸弹位置、目标位置和拥堵维护策略。引导线只显示部分路径并渐小渐淡，长度有轻微显示变化；实际飞行不增加随机偏转。

当前尚未给出商业回报结论。需要长程模拟和真实操作测试，至少分别比较新手、随机操作、普通策略、高手、免费选色与接盘策略，统计每币彩票均值、分位数、长尾大奖、最长无奖励间隔和拥堵频次。
