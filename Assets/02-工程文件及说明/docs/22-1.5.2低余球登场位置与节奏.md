# 1.5.2 低余球特殊球的位置与节奏

日期：2026-10-12。覆盖1.5产品文档第5.5节的目标选择与登场时机；其他玩法与奖励单价保持原值。已冻结的1.5.0、1.5.1不修改。

低余球申请仍遵守购买/真实消费额度、同阶段最多一次、退款和免费球不触发的规则。现在申请时按机器持久节奏种子与申请序号的无状态散列选定登场余球：约60%安排余2球、40%安排余1球；资格首次已处于余1球则在余1球尝试。时机存在申请记录中，刷新不重抽，也不靠闲置时钟自动登场。资格与登场分离，因此内部资格仍可能在余2球成立，画面不会总在这一刻亮出两颗炸弹。

目标选择不再按行号从下往上找第一个当前色可消球。优先中上层：当前最高行作为深度参考，20%–65%深度权重8，最顶端锚定区权重3，下部权重1；叠加当前/下一色或其他色可利用性权重。用固定申请位置种子和球ID作加权抽样，最多两球，避免相同位置排布。中上层内部球允许成为需要先剥层或通过连锁触达的公共目标，不保证最后一球直接命中。

保留已有球ID、颜色、位置和系统来源，仅增加炸弹属性；不额外生成球、不送彩票、不改炮内或下一球颜色。总炸弹上限仍12；无普通系统候选或达上限仍延后/跳过。旧存档未出现的历史申请没有新时机字段时按原余2球规则继续，已出现炸弹不搬家。新申请才使用新位置与时机，不清空存档。

验证：120个不同初始种子、每个实际付费射击9球，共240颗机会炸弹，134颗在余2球登场、106颗在余1球登场；中上层倾向明显。数据来自原型模拟，不代表真人商业复投率。另有80种子加权位置/身份守恒测试、余1球时机保存恢复与不重复登场测试；既有79项核心反馈回归通过。

位置/时机实现位于game/src/core/low-opportunity.mjs；报告在output/verification/v1.5.2/opportunity-distribution.json。音画与规则结合的浏览器验收另见同目录upgrade/。
