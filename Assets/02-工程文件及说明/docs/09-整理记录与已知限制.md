# 1.0整理记录与已知限制

整理基线：用户已认可的V15。日期：2026-10-11。

## 已实施

- game/成为独立运行工程，玩法核心来自gameplay-v6，表现与反馈来自demo-v15，Babylon.js移入自己的vendor目录。
- 将运行源码分成client/core/presentation/feedback，使用相对模块导入；图片、字体、声音集中在assets。
- 分离测试API与运行编排、持久化键集中管理，保留V15原键和4210地址。
- 移除已经停用的重复ResultEffects消除系统；当前EffectsUI继续承担消除与领奖，避免双重事件效果。
- 活跃源码只保留运行模块，不混入各Agent单独预览服务器、预览HTML、生成合辑和过期交付说明。
- 统一Prettier排版，新增工程版本、开发工具锁定、统一启动/语法检查/浏览器检查入口。
- 原测试去掉机器专用Chrome和Playwright绝对路径，支持安装依赖和BROWSER_PATH；报告输出独立于源码。
- 测试按游戏时钟测量瞄准持续时间，避免无头浏览器低帧率误判。固定24发不保证随机盘面必定完成阶段奖，阶段规则改由核心测试验证。
- 历史版本、Agent交付、设计草案和旧输出按类别归档。没有删除原始交付或录屏。
- 当前录屏仍在output/recordings/bubble-arcade-v15-10s.mp4，原下载路径保留。

详细移动路径见archive-map.json。历史目录的旧启动器可能仍写着原路径或旧端口，它们是原始参考档案；恢复旧版需要按原目录关系重新放置并使用独立端口。

## 此次不是哪些改动

没有新增玩法、重新抽商业奖池、改奖励倍率、实现后台、联网、原生设备或APK。规则配置version和schema保持原样，原BrowserJsonStore的持久性保证没有提升。

## 已知技术债

1. app仍承担较多编排，下一步可进一步拆输入、生命周期和设备适配，但不应同时改结算规则。
2. PresentationScene/FullScene/Region是继承结构，仍保留旧隐藏宠物的初始化和部分旧局部方法/资源；此次不做大规模渲染重写。
3. style.css保留历史级联覆盖，已排版但尚未全面合并选择器；后续应在截图/计算样式对照下整理，避免改视觉。
4. 部分坐标、球图集颜色数量和目标槽位写在表现层，尚无统一布局配置。
5. 本地账务保存全量JSON，receipt/reward/evidence记录会增长；原型满足当前检查，不等于长时设备可靠性已验证。
6. 页面可通过?test=1打开开发测试能力，正式封装前需关闭测试入口和演示控制台。浏览器端目前无防篡改能力。
7. 数值参数为实验值，未完成商业目标、玩家分布、免费选色收益和公共接盘影响的长程验证。
8. 素材清单保留原始来源，但语音字幕、音频和原hash不是全部最新一致；正式资产生产需重新核对。
9. Android GPU性能、原生存储、投币去抖、出票回执和断电恢复仍待实物验证。
