# 1.6.0 公网IP试玩部署

部署日期：2026-10-12。访问地址：http://8.134.94.47/ 。用途：同事浏览器试玩。

## 已部署范围

游戏来自不可覆盖的 `output/releases/v1.6.0/source/game/` 冻结文件，仅发布 index.html、style.css、src、assets、vendor。开发工具、测试、历史档案、产品文档、SSH密钥不上传到公开目录。

这是静态浏览器游戏。每个浏览器分别保存盘面、剩余泡泡和彩票账务，不共享玩家存档；投币和出票仍为模拟。服务器没有新增游戏管理后台、真实支付或硬件出票功能。

## HTTP兼容差异

IP直接通过HTTP访问时，浏览器不提供原生 crypto.randomUUID。部署副本新增 src/client/http-compat.js，并在游戏入口前加载。使用 crypto.getRandomValues 生成16字节随机数，按UUID v4版本/variant位转换成UUID，保持模拟投币流水ID格式与唯一性设计。没有修改玩法、概率、存档键或美术音效。原始1.6.0封版和工作工程均未修改。

HTTP试玩使用键盘。浏览器需要用户点击开启音乐或操作游戏后才能播放声音。安卓硬件、手柄等最终部署能力仍需按原计划联调，不以本次IP试玩替代。

本地部署材料位于 `output/deployment/`：v1.6.0-http目录、tar.gz部署包、浏览器验收JSON、截图、服务器known-hosts文件。SSH密钥不包含在此目录；部署使用当前用户专属权限的 `C:/Users/peter/.ssh/bubble-deploy/sentiquant_server_ed25519`。原密钥未修改。

## 更新与回退

1. 从下一版认可的冻结源码另建部署副本，不覆盖冻结版。
2. 仅打包公开资源，保留HTTP兼容模块；上传到新的独立release目录。
3. 在切换前记录current原先指向的路径，用 `readlink /var/www/bubble-arcade/current` 查看。
4. 确认资源完整后，将current链接切换到新release的site；如修改Nginx配置，先执行 `nginx -t` 再 `systemctl reload nginx`。
5. 用公网地址检查模拟投币、发射、声音、存档和资源请求。需要回退时将current链接恢复至记录的旧site路径。
6. 不清空浏览器localStorage；未来改变存档结构时先实现迁移并验证旧账务。

本次Nginx为新安装，保留其默认站点文件；通过server_name匹配公网IP进入游戏站点。无需域名，公网80已实测可达。
