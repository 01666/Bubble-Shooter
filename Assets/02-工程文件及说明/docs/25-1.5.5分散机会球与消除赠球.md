# 1.5.5 分散机会球与大消除赠球

日期：2026-10-12。

## 分散登场

同一批机会球选出第一颗后，后续候选同时考虑与本批已选球的最小物理距离。存在间距至少2.5个横向格距的候选时，优先从这些候选选择；更近位置大幅降权，空间不足再放宽。依然叠加中上层/可利用性权重、固定位置种子，不搬动或改色、不缩减整批数量。已存在的历史炸弹不重新排布。

60种子完整盘面五球登场测试中，各同批球对均保持至少2.5格距。狭小残局不保证绝对间距，优先完成已抽中数量。

## 赠球规则

一次有效发射结算，按实际移除的唯一球ID总数计算，包含普通直接消除、炸弹/闪电附带清除和最终无支撑掉落；同一球不重复计数。6颗及以下不赠，7颗赠2、8颗赠3、9颗赠4、10颗及以上赠5。一次按最高档发放，不叠加2+3+4+5。

赠球是能够继续正常消除和获票的发射次数，不是免费选色试射。直接加到可发射泡泡数，可以避免余额耗尽；已有彩票照常发放。免费试射、补球、维护、退款和纯特效不触发赠球。赠出的球也能通过真实消除再获赠球。赠球不算投币，不为低余球机会提供额外购买额度。

新增耐久ammoBonus账：累计赠球量、以发射ID:ammo为唯一奖励ID的每笔数量/清除规模。额度守恒更新为购买球数+累计赠球−有效已结算发数−当前在途球=余球。旧存档补零账，不追补历史消除；奖励随结算原子提交，保存失败不播放未入账奖励，刷新不重复发。原schema/配置/存储键保留。

ammoBonusEarned已提交事件包含发射ID、唯一奖励ID、赠球数量、清除量和新余球；paidShotResolved新增bonusAmmo，remainingAmmo采用赠后额度。赠球让额度回升至2以上时，未出现低余球申请按现有恢复规则结束，已出现公共炸弹保留。

## 明确反馈

非开箱大消除显示“ 大消除！赠送X颗泡泡 ”，次行写实际清除颗数与彩票数；绿色描边、原短弹出/亮粒效果，持续约2.3秒。同发宝箱仍以开箱为主，次行明确追加“赠X颗泡泡”，避免两个大字卡片重叠。

专用ammo_bonus为0.34秒上扬四音街机奖励声，归入原SFX混音和暂停/静音生命周期；一次奖励只播放一次，和逐张+1声区分。不声称新增真人语音，自然语音槽位仍为空。音频缓冲现在32个WAV+得分合成音+赠球合成音=34。

## 验证

88项核心与反馈测试通过，含真实七球清除→赠2球、在途刷新后只结算一次、旧账补零、免费不赠、赠球账守恒、各档门槛及唯一ID去重。另有60个种子同批5球间距检查、22发实机机制集成，以及真实浏览器七球清除展示：余球从10经发射变9再赠2至11，获票7张，一次赠球音效，暂停/刷新不重领。
